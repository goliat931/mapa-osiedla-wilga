# Mapa Osiedla Wilga

Interaktywna, robocza mapa Osiedla Wilga (gm. Wilga) — oddolna inicjatywa mieszkańców w ramach Przedsięwzięcia nr 3.

**Mapa:** https://goliat931.github.io/mapa-osiedla-wilga/

Zawiera ulice i numery domów, przejezdność dróg dla wozów OSP, hydranty i zbiorniki, stromizny, wodę i miejsca charakterystyczne.
Przejezdność i stromizny są wstępne — do potwierdzenia z jednostkami OSP.

Źródła: adresy — PRG (GUGiK), nazwy ulic — eTeryt (GUS), drogi i woda — © OpenStreetMap, model terenu — NMT GUGiK, sieć wodociągowa — GESUT (Starostwo Powiatowe w Garwolinie).

Dane w `data/` są generowane z projektu QGIS skryptem `eksport.py`.
